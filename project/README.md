# Car Damage Vision: Система сегментации повреждений автомобиля

Данный проект представляет собой программный комплекс для автоматического обнаружения деталей и повреждений автомобилей на изображениях с использованием алгоритмов глубокого обучения (**Instance Segmentation**).

Проект разработан в рамках курса «Инженерия искусственного интеллекта» и демонстрирует полный жизненный цикл разработки ИИ-решения: от постановки задачи и анализа данных до развертывания веб-интерфейса с наблюдаемостью.

## Ключевые особенности

- **Современная архитектура:** Использование нейросети `Mask R-CNN` (ResNet-50 FPN V2) для точного выделения контуров объектов.
- **Сравнение моделей:** Включает HSV CV-бейзлайн, Mask R-CNN MobileNetV3, FCN ResNet-50.
- **Масштабируемый пайплайн:** Автоматическая загрузка данных с Hugging Face и конвертация в стандарт COCO.
- **Train/Val/Test сплиты:** Полноценное разбиение данных с hold-out тестовой выборкой.
- **Трекинг экспериментов:** Интеграция с MLflow для логирования параметров и метрик.
- **Подбор гиперпараметров:** Optuna для автоматической оптимизации.
- **Инструментарий исследователя:** Поддержка прерывания и возобновления обучения (`resume`), генерация графических отчетов (Loss, mIoU, Precision/Recall).
- **Интерактивное демо:** Веб-приложение на `Streamlit` для визуализации работы модели в реальном времени.
- **API с наблюдаемостью:** FastAPI-сервис с Prometheus-метриками, структурированным логированием и health-check.
- **Поддержка 29 классов:** От кузовных деталей до специфических повреждений (вмятины, коррозия, сколы).

## Архитектура системы

Проект организован по модульному принципу:

| Модуль | Назначение |
|--------|-----------|
| `src/car_damage_segmentation/data.py` | Загрузка, аугментация (`albumentations`) и парсинг аннотаций. |
| `src/car_damage_segmentation/modeling.py` | Конфигурация и инициализация модели Mask R-CNN. |
| `src/car_damage_segmentation/engine.py` | Циклы обучения и валидации с AMP. |
| `src/car_damage_segmentation/metrics.py` | Расчет метрик IoU и точности на уровне масок. |
| `src/car_damage_segmentation/inference.py` | Логика предсказания и отрисовки результатов. |
| `src/car_damage_segmentation/baselines.py` | Классические бейзлайны (HSV CV, MobileNetV3, FCN). |
| `src/car_damage_segmentation/utils.py` | Утилиты, логирование, работа с JSON. |

## Быстрый старт

### Установка зависимостей
```bash
pip install -r requirements.txt
```

### Подготовка данных
```bash
python -c "from src.car_damage_segmentation.data import prepare_hf_car_dataset; prepare_hf_car_dataset()"
```

Данные будут загружены в `data/raw/` и обработаны в `data/processed/`.

### EDA (анализ данных)
```bash
jupyter notebook notebooks/01_eda.ipynb
```

### Обучение модели
Для запуска обучения с нуля:
```bash
python train_instance_segmentation.py --epochs 10 --batch-size 4
```

Для обучения облегчённой модели:
```bash
python train_instance_segmentation.py --epochs 10 --backbone mobilenetv3
```

С MLflow-трекингом (запустите MLflow UI в отдельном терминале):
```bash
mlflow ui --port 5000
python train_instance_segmentation.py --epochs 10 --batch-size 4
```

Для продолжения обучения с сохраненного чекпоинта:
```bash
python train_instance_segmentation.py --epochs 5 --resume outputs/best_model.pth
```

### Сравнение моделей
```bash
python compare_models.py
```
Отчёт будет сохранён в `outputs/model_comparison/comparison_report.md`.

### Подбор гиперпараметров (Optuna)
```bash
python tune_hyperparameters.py
```
Результаты сохраняются в `outputs/hparam_tuning_report.json`.

### Генерация отчета
После обучения можно создать графики метрик:
```bash
python generate_report.py
```
Отчет будет сохранен в `outputs/training_report.png`.

### Запуск API-сервиса
```bash
python main.py
```
API доступен на `http://localhost:8000`:
- `GET /health` — проверка работоспособности
- `GET /metrics` — Prometheus-метрики
- `POST /predict` — инференс (передать файл изображения)

Swagger-документация: `http://localhost:8000/docs`

### Запуск веб-интерфейса (Streamlit)
```bash
streamlit run app.py
```

### Запуск в Docker
```bash
docker-compose up --build
```
Сервисы:
- API: `http://localhost:8000`
- UI: `http://localhost:8501`

## Результаты и анализ

Текущая модель обучена на датасете `DrBimmer/car-parts-and-damage-dataset`.

- **Метрики:** Модель демонстрирует стабильное снижение Loss и рост mIoU при увеличении количества эпох.
- **Визуализация:** Результаты инференса показывают высокую точность локализации крупных деталей и уверенное распознавание явных повреждений.
- **Сравнение:** Mask R-CNN ResNet-50 показывает лучший mIoU, MobileNetV3 — лучшую скорость инференса.

### Ключевые выводы EDA

1. **Дисбаланс классов:** Деталей существенно больше, чем повреждений.
2. **Вариативность размеров:** Изображения разного разрешения — требуется предобработка.
3. **Мелкие объекты:** Значительная доля масок <100 px.
4. **Качество аннотаций:** Полигоны детальные, ошибок мало.
